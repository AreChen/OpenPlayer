# OpenPlayer v1.6.7

Local Windows test candidate, not a published release.

- Prevents repeated stored decoding preferences from overwriting the effective
  mpv decoding mode shown while a native presenter requires software decoding.
- Rejects hardware decode switching while a native presenter owns the output.
  Saved user preferences remain intact; stopping the presenter restores the
  original decoder configuration.

XeFG 0.1.1 remains compatible and unchanged. This update does not add MFG modes.
The user's test of 1.6.6 reported the earlier media issue resolved, with decoding
mode flicker remaining. Windows x64 NSIS is the local test package; macOS is deferred.

Verification: 15 frontend tests, 220 Rust tests (3 ignored), shell checks, Clippy
and the Windows package build passed. The real GPU-1 presentation harness rejected
a hardware decode override, continued generating frames and completed detach,
crash recovery and Alt+F4 (`target/xefg-decoding-ownership.log`).

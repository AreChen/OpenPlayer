# OpenPlayer v1.6.8

Local Windows test candidate, not a published release.

- Windows native presentation supports hardware decoding with readback and
  respects the user's software decoding selection.
- Attempts NVIDIA `nvdec-copy` on the plugin's exactly matched GPU, falling back
  to software decoding when unavailable. Intel/AMD hardware-copy is not included.
- Decoding can be switched while paused; detach restores the output/device and
  retains the user's latest decoding choice. Active presentation reports the
  actual decoder rather than the requested mode.
- Retains 2x mode; no MFG or shared-texture extensions are added.

Local test package: Windows x64 NSIS. Existing XeFG 0.1.1 packages remain compatible.

Verified with the installed XeFG 0.1.1 package on the explicitly selected second
RTX 3080 Ti: 1080p60 AV1 hardware-copy and software decoding, automatic attachment,
paused decode switching, seek/resume, resize/fullscreen, detach, process-crash
recovery and Alt+F4 cleanup. An unsupported raw-video codec uses software fallback.
The presenter test caps source delivery at 30 fps; this is not a 60-to-120 fps
performance claim. HDR/Dolby Vision hardware-copy has not been validated.

NR 0.4.0 plus XeFG 0.1.1 also passed on the same selected GPU with hardware-copy
decode: 12.018 seconds elapsed / 12.000 seconds media progression, 180 source and
179 generated frames at the existing 15 fps NR input cap. Paused NR updates,
detach/crash recovery and process cleanup passed. This short mpv clock sample
does not measure physical display/audio latency or long-session stability.

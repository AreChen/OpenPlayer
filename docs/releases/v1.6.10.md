# OpenPlayer v1.6.10

## Changes

- Add configurable keyboard shortcuts and icons for plugin actions.
- Let native video plugins measure and adapt to available processing capacity.
- Coalesce rapid seeks and discard superseded seek responses.
- Support composing native enhancement with frame generation.

## Plugins And Limits

- DLSSNR 0.6.0 and XeFG 0.3.0 are optional Windows plugins, distributed
  separately. When combined, enhancement runs before frame generation.
- XeMFG CUDA and higher frame-generation multipliers are experimental. Their
  output quality, actual display rate, and long-term stability are not guaranteed.

## Packages

- Windows x64 NSIS installer
- Linux `.deb` and AppImage
- SHA256 checksum files

macOS is deferred for separate validation.

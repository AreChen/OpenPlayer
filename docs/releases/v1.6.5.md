# OpenPlayer v1.6.5

Local Windows test candidate. Not yet published or user-accepted.

## Changes

- Adds the experimental `present-rgba-v1` native plugin adapter, with bounded
  CPU RGBA transport, explicit presentation ownership and supervised cleanup.
- Keeps the existing mpv core, audio clock and transparent controls while a
  separate native plugin process presents video. Supports output restoration,
  pause redraw, seek resets and dynamic window dimensions.
- Fixes an output-switch readiness race and rejects recursive plugin directory
  imports that contain their own installation directory.
- Caps presentation input by dropping frames, without duplicating slower NR
  output. Keeps mpv render acknowledgements active during output teardown.

## Compatibility

- XeFG 0.1.0 is a separate optional plugin, not part of the player installer.
- This presentation path requires seekable SDR BT.709 filter output. It uses
  software decoding/rendering, not shared GPU textures or HDR passthrough.
  GPU shaders and GPU-output color adjustments are not preserved.
- Native XeFG 2x and a short NR-to-XeFG composition run passed on GPU 1,
  including paused NR updates, worker crash recovery and application close.
  Sustained A/V behavior, real UI integration and user image-quality acceptance
  remain pending. This is not a physical display FPS or quality guarantee.
- macOS work remains deferred. Existing two-window controls are preserved.

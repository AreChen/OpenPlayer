# OpenPlayer v2.0.0

## Changes

- Ship the GPUI Fast player in the Windows installer with D3D11 video composition, native controls and settings, and GPUI Motion transitions.
- Use the transparent OpenPlayer mark in the empty player and About settings. The mark follows the active theme accent.
- Use the charcoal-backed OpenPlayer icon for desktop packages.
- Run the Windows player and installer without a WebView runtime. The Windows build focuses on core playback while the plugin SDK is deferred.
- Restore window dragging from the video, wheel volume with on-screen feedback, configurable shortcuts, and a smooth progress and frame display.
- Keep the custom maximize button clear of the Windows Snap Layout flyout. Add themed tooltips, a compact speed button, a translucent volume popover with a centered value, and animated H/S icons for decoding.
- Open and append media in a theme-aware file browser with an editable address bar, a remembered directory, folder and media favorites, drive navigation, and video thumbnails with silent hover previews. Press Ctrl+F to search filenames in the current folder and its subfolders with live scan counts. Press Ctrl+Shift+. to toggle dot-prefixed folders. The search bar and directory cards animate when Windows animations are enabled. Double-clicking the empty stage opens the browser immediately while folders load in the background.
- Keep the browser's sort order, category, and media filter across restarts. Show folders by default and resume browsing in the last folder or the folder of an explicitly opened local file.
- Use native context menus to play, locate, and favorite items in the file browser. View and copy container, video, audio, and track details from both the browser and the playback menu.
- Initialize the Windows playback core and video surface on first use. Release them on Stop and release the thumbnail decoder when the browser closes.
- Close OpenPlayer in the selected installation directory before updating or uninstalling. Choose to open OpenPlayer or Windows Default Apps on the installer finish page.
- Show the effective Windows default player coverage in Playback settings and open the system page for confirming associations.
- Fit the window to the video aspect ratio by default. Drag the window edge to keep a custom size and press Ctrl+H to resume fitting. Keep primary controls visible in narrow windows and put secondary actions in the overflow menu.
- Expand the playlist when opening multiple media files, and animate the audio-only stage during playback.
- Restore same-folder subtitle matching, the HLS live stream compatibility options, and Windows Explorer preview registration in Settings.
- Import existing 1.x player shortcuts from the standard Windows LevelDB profile on first use when no native shortcut preferences exist.
- Check for stable 2.x updates in the background. About can also check immediately, download the package matching the installed platform, architecture, and package type, and verify its SHA-256 before handing off to the native installation flow.
- Existing 1.x installations continue to use GitHub's 1.x Latest release. To move from 1.x to 2.x, download the installer for your platform from this release.
- Add separate theme opacity settings for the title bar and transport. During playback, the chrome hides on pointer exit and the chrome and cursor hide after three seconds of inactivity.
- Bundle the official libmpv 0.42.0 LGPLv3 runtime on Windows x64.

## Packages

- Windows x64 NSIS installer with GPUI Fast, D3D11, and libmpv
- Linux x64 `.deb` and AppImage with embedded libmpv playback under X11
- macOS DMGs for Apple Silicon and Intel with bundled libmpv and ad-hoc app signatures. These DMGs are distributed without Apple notarization.
- SHA-256 checksum files for every installer and `release-assets.json` with the source commit

# OpenPlayer v1.6.6

Local Windows test candidate. Not published or user-accepted.

- Adds `inputConversion: "sdr-bt709"` to the native presentation adapter,
  reusing the existing Dolby Vision-aware conversion graph. SDR input bypasses
  conversion; HDR/Dolby Vision is converted to SDR, not passed through as HDR.
- Presenter-owned conversion is removed on detach, failure cleanup and stop.
- XeFG 0.1.1 is a separate plugin with an explicit fixed 2x multiplier and
  advanced pre-FG frame cap / processing size limit controls.

The presentation path still uses CPU RGBA transport. Conversion device selection
is independent of the XeFG adapter. No new 3x/4x or super-resolution support is
claimed. macOS work is deferred.

Windows x64 NSIS installer and separate XeFG `.opplugin` are local test artifacts.
The updated SDR bypass passed real-package pause/fullscreen/crash recovery and
Alt+F4 checks on GPU 1 (`target/xefg-011-sdr-bypass.log`). Rust tests: 220 passed,
3 ignored. Shell, frontend, SDK and simulated plugin UI checks passed.
Real Dolby Vision regression is pending permission to run the mpv color
conversion, which may use GPU 0 while the user is gaming. The reported input
is 3840x1606, 25 FPS, Dolby Vision Profile 5. Picture quality remains unverified.

# OpenPlayer v1.6.4

## Changes

- Adds trusted native plugin modules with bounded control RPC, runtime integrity
  checks, process ownership and cleanup on stop, disable, upgrade, uninstall and exit.
- Adds Windows x64 single-stage native video attachment, optional HDR/Dolby Vision
  to SDR conversion, input frame-rate limits and paused-frame refresh.
- Improves shared plugin selects and checkboxes. Side panels reserve window-button
  and playback-control space with a 12px gap instead of covering those controls.
- Improves playback/plugin synchronization and fixes Windows fullscreen bounds
  and coordinated main/overlay window closure.

## Compatibility

- Native plugins are trusted code, not sandboxed. Installation grants declared
  permissions without repeated launch prompts. Install only trusted packages.
- DLSSNR remains a separate optional Windows plugin, not bundled with the player.
  Version 0.4.0 defaults to a selectable 15 FPS processing cap. This trades motion
  smoothness for processing capacity without slowing audio; it is not 60 FPS inference.
- HDR/Dolby Vision conversion outputs SDR. Multi-stage execution, GPU zero-copy,
  interpolation, super-resolution and HDR-preserving NR are not included.
- The user accepted the Windows/NR build. Existing GPU tests cover paused previews,
  short 1080p59.94 synchronization, explicit GPU selection and resource cleanup;
  they do not establish sustained 4K performance.

## Packages

- Windows x64 NSIS installer
- Linux `.deb` and AppImage
- Unsigned macOS arm64 and x64 DMG
- SHA256 checksum files

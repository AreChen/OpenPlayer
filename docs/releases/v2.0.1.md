# OpenPlayer 2.0.1

Windows, macOS and Linux now ship the same native Rust and GPUI Fast interface. This release brings the themed media browser, playback controls and settings to macOS and Linux, and introduces the Rust plugin SDK on all three platforms.

## What’s new

- Use the editable path, recursive search, thumbnails, favorites and saved filters in the native media browser. The player remembers the last folder and fits the playback window to the video’s aspect ratio.
- Use **Settings → Plugins** to open a network stream, save a PNG of the current frame or adjust subtitle size. The subtitle plugin is written in Rust and runs as WebAssembly. [Rust plugin SDK](https://github.com/AreChen/OpenPlayer/blob/v2.0.1/docs/plugins/native-sdk.md)
- Play in a GPUI window on Linux under X11 or Wayland. Windows uses D3D11 video composition, and macOS and Linux present libmpv frames in the GPUI scene.
- Check for stable 2.x updates in **Settings → About**. OpenPlayer selects the package for the installed platform and architecture and verifies its SHA-256.

## Downloads

| Platform | Package |
| --- | --- |
| Windows x64 | NSIS installer, including libmpv 0.42.0 |
| macOS | DMG for Apple Silicon or Intel. The apps are signed ad hoc and distributed without Apple notarization. |
| Linux x64 | Debian package or AppImage |

The release includes a SHA-256 file for each installer and a manifest with the exact source commit. To move from 1.x to 2.x, download and run the installer for your platform.

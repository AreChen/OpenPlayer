# Documentation guide

Use the platform split in [Runtime architecture](architecture/README.md) when documenting player features. Use CI, packaging scripts and source code to check commands and claims. Keep the two root READMEs aligned.

- Record release-specific changes under [releases](releases/) and preserve published release notes.
- Document bundled native runtimes and checksums in [native-deps](native-deps/README.md).
- See the [plugin documentation guide](plugins/AGENTS.md) for SDK 1.6 and historical material.

Run `git diff --check` and verify new relative links.
